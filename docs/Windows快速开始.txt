爪爪来信 · 给小猫的使用说明（Windows 10 / 11，64 位）

你只需要准备两个东西：
① 从 GitHub 下载的 PawBridge_0.1.3_x64-setup.exe 安装文件
② 一整段以 PB1. 开头的邀请口令

第一次使用

1. 登录已获仓库访问权限的 GitHub 账号，打开：
   https://github.com/whiteplanck/pawbridge/releases/tag/v0.1.3
   在 Assets 里下载 PawBridge_0.1.3_x64-setup.exe（不用下载 Source code）。
   保存到电脑，双击打开，按中文提示完成安装。
   如果提示补装 Microsoft Edge WebView2，保持联网，让安装程序完成。

2. 打开 PawBridge（爪爪来信）。昵称默认是“小猫”，可以改成你喜欢的名字。

3. 把对方发来的整段邀请口令粘贴进去，点“领养小猫”。
   不用填写服务器地址，也不用安装 Node 或输入命令。

以后怎么用

打开 PawBridge 就能继续使用，不需要重复配对。
点击小猫，查看对方的心情和计划。
点“我的今天”，填写心情和计划，再点“分享给对方”。
点“想你了 · 串门”，你的小猫就会去对方的小狗身边跳一下、冒个爱心再离开。
收到对方的“想你了”，你的小猫旁就会出现来访的小狗；收起面板也能看到。
点“摸摸头”“送零食”，也会给对方送去招呼。
打开“互动”页，还能选择抱抱、亲亲、加油、早安、晚安、喝水提醒。
修改“互动文字”，点发送，对方的气泡和信箱里会显示你写的话。
每种互动的常用文字都会单独记在本机，重新打开还在；修改本身不会发送。
“恢复默认文字”可还原，留空发送也使用默认文字。首页三个快捷招呼沿用你保存的文字。
气泡最多显示两行，长文字可以到信箱里完整查看。
也可以写小纸条。忙碌和休息时，收到招呼也照常播放动画。
点面板右上角的“−”，可以收起成小猫；按住 ⠿ 拖动位置。
小信箱里的消息，读完后点“这些都读过啦”。
软件目前不会开机自动启动；重启电脑后从开始菜单打开 PawBridge 即可。

已经安装旧版？

先退出 PawBridge，运行新版安装文件覆盖安装，不要清除应用数据。
原来的配对和消息会保留，不需要重新输入邀请口令，也不需要重新部署服务器。
双方升级到 0.1.3 后都能体验新的互动类别和自定义文字；旧版仍能收发，新类别会作为带标题的纸条显示。
通常约 15 秒同步一次，网络不好时会更慢；动画结束不等于对方已读。
连续招呼依次播放，最多连续排入 5 条动作，其余消息仍在信箱中。
系统开启“减少动态效果”时，来访宠物静态显示，不跳动。

遇到问题

“邀请过期”：请对方重新生成一段口令，旧口令只有 24 小时有效。
“小家暂时连不上”：让对方检查同步服务。不要随意卸载或清理软件数据。
“GitHub 页面显示 404”：仓库是私有的，请确认登录了正确账号，并已接受仓库访问邀请；仍打不开时让对方检查权限。

这是预览版，安装包尚无 Windows 发布者签名，系统可能提示未知发布者。
仅使用对方从项目下载的安装文件；如果系统或公司电脑阻止安装，把提示发给对方处理，不需要关闭安全软件。

提示：邀请口令由对方配置好在线服务后生成。只安装软件还不能代替在线同步服务。
