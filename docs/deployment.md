# 让珠海和北京连起来

## 需要什么

一个能持续运行 Node.js 24、能保存 SQLite 文件、双方都能访问的 HTTPS 服务地址。可以选择带持久磁盘的应用托管，或者小型云服务器。不需要租机房，不需要给两台电脑分别买服务器。GitHub Pages 不能运行这个后端；无持久磁盘的函数服务也不适合直接保存 SQLite。

已有 Linux VPS、没有域名，或 443 端口已被其他程序占用时，可使用可信 IP 证书和独立的 HTTPS 端口，见[已有 VPS 的 IP HTTPS 部署与维护](existing-vps.md)。不需要修改桌宠客户端，也不要关闭证书校验。

为两个人设计，先从低规格实例开始即可。Compose 将应用内存上限设为 256 MB，这不是实测容量承诺；宿主系统和 HTTPS 代理还需要额外内存。选择平台时先从珠海和北京测试连接，再决定是否付费。本文不绑定供应商，也不预设费用。

## 方案一：小型云服务器 + Docker

1. 准备域名，将 DNS 指向服务器，安装 Docker Compose 和宿主机 Caddy。
2. 克隆私有仓库。推荐只给服务器这个仓库的只读部署密钥，不复制个人 GitHub 令牌。
3. 在项目根目录创建 `.env`，只填：

   ```dotenv
   PAWBRIDGE_SETUP_KEY=替换为至少24字符的随机建家密钥
   ```

   可以运行 `openssl rand -hex 24` 生成。`.env` 已被 Git 忽略。密钥只在小狗首次建家时填写，猫用配对码加入；不要放进前端代码或 GitHub Actions 日志。

4. 启动服务：

   ```sh
   docker compose --env-file .env -f deploy/compose.yaml up -d --build
   curl http://127.0.0.1:8787/health
   ```

5. 按 `deploy/Caddyfile.example` 配置宿主机 Caddy，替换域名，确保 HTTPS 可访问。应用端口只绑定服务器回环地址；公网访问由 Caddy 代理。不要直接把 8787 暴露到公网。
6. 你们的应用都填 `https://你的域名`。你选小狗、珠海，输入建家密钥，得到配对码；她选小猫、北京，用配对码加入。

服务必须部署在域名根路径，目前不支持 `/pawbridge` 一类子路径。生产客户端只接受 HTTPS；HTTP 仅允许本机回环调试地址。域名和证书由所选平台或 Caddy 管理。

## 方案二：支持持久磁盘的应用托管

- 使用仓库根目录为构建上下文、`deploy/Dockerfile` 为 Dockerfile。
- 挂载可写持久磁盘到 `/data`，确保容器内 `node` 用户（UID 1000）可读写。
- 设置 `PAWBRIDGE_SETUP_KEY` 为至少 24 字符随机值，端口为 `8787`，健康检查 `/health`。
- 开启平台 HTTPS 域名，只运行 **一个实例**。SQLite 版本不支持多个实例共享网络磁盘。
- 容器启动自带 `HOST=0.0.0.0` 和数据库路径；不要把客户端身份令牌作为部署密钥。
- 休眠平台会增加唤醒延迟，客户端会自动重试。没有持久存储的平台重启会丢失配对和消息，不能用于实际使用。

## 日常维护

升级前备份数据库。最简单的方式是在维护时停止服务，再归档 Docker 命名卷或拷贝整份数据目录，完成后重启。运行中的 SQLite 使用 WAL，不要只拷贝 `.sqlite` 主文件。托管平台可用一致性磁盘快照。备份包含私人内容，应限制访问并定期清理。

更新代码后执行与首次启动相同的 Compose 命令。不要执行 `docker compose down -v`，它会删除保存配对和消息的持久卷。恢复备份时停止服务，恢复完整数据目录并保留正确文件权限。

`GET /health` 只表示进程可响应。用双方客户端互发纸条，才算完成端到端部署验收。若天气失败但消息正常，检查服务设备对 `api.open-meteo.com` 的访问；天气由客户端直接请求，不经过你的同步服务器。

默认允许 Tauri Mac／Windows 来源和本地 Vite 来源。如果额外托管网页客户端，设置 `ALLOWED_ORIGINS` 为逗号分隔的精确来源，并保留默认桌面来源：`tauri://localhost,http://tauri.localhost,https://tauri.localhost`。不使用 `*`。代理后按实际 socket 地址共享限流额度，足够两人使用；当前不信任 `X-Forwarded-For`。

## 这版的数据保护范围

- 32 字节随机身份令牌，服务端存摘要；配对码存摘要、24 小时过期、仅可使用一次。
- 消息和近况按配对隔离；只有接收者能标记自己的消息已读。
- 外网建家必须有密钥；配对接口限流、JSON 请求限长、文本长度受限。
- 不收集实时位置、应用活动、屏幕、摄像头或麦克风内容。
- 当前无端到端加密、设备撤销、账号恢复或自动数据迁移；请按两人自用的早期版本维护。
