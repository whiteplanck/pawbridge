# 让她安装后直接加入

她不用部署服务器。你们只需要一份双方可访问的在线同步服务，由建立小家的一方准备；她只安装 Windows 客户端并粘贴邀请口令。

## 你先准备一次

1. 按 [部署说明](deployment.md) 部署在线服务，确认 HTTPS 地址可用。目前仓库没有提供公共同步服务。
2. 安装 0.1.1 或更高版本的 Mac 客户端。第一次打开时，展开「建立小家或本机测试」，填写在线服务地址、你的昵称、珠海和建家密钥，选择小狗建家。
3. 如果已经用 0.1.0 在本机测试，升级会保留已有身份。点「连接设置」再配置线上小家；成功后切换，失败或取消仍保留原连接。先处理待寄消息和未分享的修改。
4. 点「复制给她的邀请口令」。口令以 `PB1.` 开头，包含 HTTPS 服务地址和一次性配对码，不含你的身份令牌或建家密钥。只发给她，24 小时内使用。仅有 `127.0.0.1` 本机服务时无法生成异地邀请口令。
5. 仓库是私有的，先让她的 GitHub 账号获得仓库访问权限并接受邀请。把 [0.1.3 下载页](https://github.com/whiteplanck/pawbridge/releases/tag/v0.1.3) 和 [Windows快速开始.txt](Windows快速开始.txt) 链接发给她，她可以自己下载 `PawBridge_0.1.3_x64-setup.exe`。邀请口令由你在桌宠中复制后单独发给她。

## 她的操作只有三步

1. 登录 GitHub，从下载页的 Assets 下载 Windows 安装文件，双击后按中文提示安装。
2. 打开 PawBridge，粘贴你的邀请口令（昵称默认「小猫」，可修改）。
3. 点「领养小猫」。之后重新打开软件会自动连接，不需要再次输入口令。

城市默认为北京。她不需要知道服务地址、建家密钥、Node、Docker 或终端命令。只有你这边需要部署在线服务；安装包不虚构一个可用的公共服务。

## 已经配对，更新后怎么串门

双方先退出桌宠，再覆盖安装 0.1.3，保留应用数据即可继续原来的配对；同步服务器不用更新。点「想你了 · 串门」，她的小猫旁会出现你的小狗，你这边也能收到来访的小猫。收起面板也能看到，忙碌／休息不阻止招呼。动作结束后消息仍在信箱，不代表对方已读。

打开「互动」页可选 9 种类别，包括抱抱、亲亲、加油、早安、晚安和喝水提醒。修改文字后点发送，对方气泡和信箱都会显示；每种文字在本机单独记住，不自动发送。旧版仍兼容：新类别会作为带标题的普通纸条显示，双方更新后才能完整体验新动作。

## 安装与使用边界

Windows 安装器配置为当前用户安装、简体中文界面。使用系统 WebView2，缺少时联网下载安装，避免把完整浏览器打进安装包；正常使用也需要联网。不承诺绕过系统的发布者签名提示或公司电脑的安装限制。

当前仍是未做发布者签名的预览版。遇到 Windows 拦截应核对文件来源并由你协助处理，不要求她关闭安全软件。断网后消息会重试；重新配对不会自动迁移旧小家的历史。开机自启和自动更新尚未实现。

安装器配置参考 [Tauri Windows 安装说明](https://v2.tauri.app/distribute/windows-installer/)及 [配置参考](https://v2.tauri.app/reference/config/)。
